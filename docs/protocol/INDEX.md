# ORC Protocol Documentation

This directory contains the protocol specification and architectural documentation for ORCa.

## Files

- [architecture.md](architecture.md) — Protocol design, request/response flow, and internal architecture.
- [protocol.md](protocol.md) — ORC protocol specification: command format, argument parsing, resource/function resolution, help text generation.
- [auth.md](auth.md) — Authentication configuration: env vars, auth methods (bearer, basic, apikey), injection rules.
- [mcp-tools.md](mcp-tools.md) — MCP tool reference: command_line tool schema, input/output format, help variants, error handling.
- [usage.md](usage.md) — General usage guide: workflows, command patterns, parameter handling, debugging tips, client integration.
